# 도형 편집기 (수학 문제 그림 만들기)

`도형편집기.html` 파일을 더블클릭하면 브라우저(Chrome/Edge)에서 바로 실행됩니다.
설치·서버·인터넷 연결이 필요 없습니다. 이 폴더는 민즐 웹사이트(Next.js)와 별개입니다.

## 진행 단계
- [x] 1단계: 기본 화면, 그림 불러오기(파일·끌어다 놓기·Ctrl+V), 그림 이동/크기/가로·세로/투명도/잠금/삭제,
  점 추가·이동·이름·크기·색·숨김, 선분(굵기·색·실선/점선·숨김), 삭제, PNG 저장(전체/도형 부분만, 클립보드 복사)
  - 덤: 실행 취소/다시 실행, 작업 저장(.json)/열기, 개체 목록
- [x] 2단계: 문자, 길이(숫자만 / "AB = 5", 글자만 / 괄호선), 각(각도 자동·직접 입력·숨김, 호 1~3개, 색칠),
  직각, 평행(한 줄~세 줄), 수직
  - 덤: 점 이름 자동 배치(선분을 피해 도형 바깥쪽) + 8방향 직접 선택
- [ ] 3단계: 좌표평면, 실제 좌표, 격자, 확대/축소
- [ ] 4단계: 실행 취소 개선, 객체 선택 개선, 속성창 개선

## 수정할 때 참고 (Claude Code용)
파일 하나 안에 구역 제목(`[설정]`, `[그리기]` 등)이 주석으로 나뉘어 있습니다.

| 요청 예시 | 고칠 곳 |
|---|---|
| 점 크기·선 굵기·기본 색·글꼴·각 호 크기·길이 표시 기본 방식 | `<script>`의 `CONFIG` |
| 버튼 색·화면 분위기 | `<style>` 맨 위 `:root` 색상 변수 |
| 왼쪽 도구 버튼 순서·이름·단축키 | `TOOLS`, `TOOLBAR` |
| 새 도구 추가 | `TOOLS`(+`TOOLBAR`) → 만들기 함수 `add…` → `finishPick` 또는 pointerdown → `DRAW.종류` → `PANELS.종류` → `refsOf`/`objLabel`/`LIST_ORDER` |
| PNG 저장 방식 | `[PNG 내보내기]` 구역 |

- 모든 개체는 `doc.objects` 배열에 `{ id, type, ... }` 형태로 따로 저장됩니다.
  type: `point`, `segment`, `text`, `length`, `angle`, `right`, `parallel`, `perp`, `image`
- 표시들은 점/선분의 id를 참조하므로 점을 옮기면 자동으로 따라갑니다. 점을 지우면 `refsOf`를 따라 연결된 것도 함께 지워집니다.
- 상태를 바꾸기 직전에 `record()`를 호출해야 실행 취소가 됩니다.
- 화면용과 PNG용 그림은 같은 `drawScene()`으로 그립니다 (화면 전용 표시는 `renderOverlay()`).
- 점은 항상 맨 위 레이어(`LAYER_OF`)여야 다른 표시에 가려지지 않고 잡을 수 있습니다.
